# Tarjetas

Un archivo por tema: `<tema>.md`. Los genera `/cards`, los usa `/repasar`.

**No hay agenda.** El campo `Visto` de cada tarjeta es historial de lo que ya pasó
(`2026-08-15:ok`), nunca una fecha futura ni un vencimiento. Las tarjetas no caducan, no se
acumulan y no reclaman nada: están acá para cuando quieras tirar de ellas.

Formato de cada tarjeta: ver `.claude/commands/cards.md`.
